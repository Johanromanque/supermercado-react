# Supermercado React

Proyecto académico de **Desarrollo Frontend II (PFY2202), Bimestre 9**, desarrollado con React para simular la interfaz de gestión de inventario de un supermercado.

## Funcionalidades — Semana 1

- **Inicio:** visualización de productos con su ID, nombre, categoría, stock y precio.
- **Nuestras Tiendas:** información de tres sucursales, incluidas sus direcciones y horarios.
- **Quiénes Somos:** presentación del supermercado, su misión y visión.
- **Navegación SPA:** cambio entre las tres páginas mediante React Router.
- **Diseño adaptable:** interfaz construida con Bootstrap y CSS.

> **Nota:** Los productos y las sucursales son datos de demostración definidos en el frontend. Los botones de agregar, editar, eliminar y ver ubicación son elementos visuales; sus acciones aún no están implementadas.

## Tecnologías utilizadas

- React
- React Router DOM
- Vite
- JavaScript, HTML y CSS
- Bootstrap 5
- Git y GitHub

## Ejecutar el proyecto localmente

Se necesita tener instalados **Node.js** y **npm**.

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Johanromanque/supermercado-react.git
   ```
2. Entrar a la carpeta del proyecto:
   ```bash
   cd supermercado-react
   ```
3. Instalar las dependencias:
   ```bash
   npm install
   ```
4. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abrir en el navegador la dirección local indicada por Vite.
